# Day 2 - Salesforce Platform Basics

## What is Salesforce Platform?

Salesforce is a cloud-based CRM platform that helps businesses manage customers, sales, services, and business processes. It provides tools for storing data, automation, development, and application building on a single platform.

---

## App, Object, and Tab

### Object
An object in Salesforce is like a database table that stores related data and records such as Accounts, Contacts, or Opportunities.

### App
An app in Salesforce is a collection of related objects, tabs, and tools grouped together for a specific business purpose.

### Tab
A tab in Salesforce is the user interface shortcut that allows users to access objects, records, or features easily.

---

## Configuration vs Coding

If a problem can be solved using the existing tools and features provided by Salesforce, we use configuration or no-code methods.

Examples:
- Creating objects and fields
- Creating workflows and validation rules

If the requirement is complex and cannot be handled through configuration alone, we use coding with Apex.

Examples:
- Creating Apex triggers
- Integrating Salesforce with external systems
